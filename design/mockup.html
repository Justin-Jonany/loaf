Design · v0.1 · 12 Aug 2026

Foolscap

A note widget that floats on your macOS desktop, backed by plain markdown in a folder you own. Dates are text. Themes are CSS. The storage format is designed so a coding agent can edit your notes with ordinary file tools — no API, no plugin, no sync service.

The vault

~/Notes/              # configurable
├── todo.md
├── thesis.md          # ```mermaid fences
├── daily/
│   ├── 2026-08-11.md
│   └── 2026-08-12.md  # today, auto-created
├── attachments/
│   └── filtration.png
└── CLAUDE.md          # the format, documented

There is no API. Notes are markdown files in one folder. An agent edits them with ordinary file tools — nothing to install, no IPC layer, nothing to break when either side changes.

The widget watches the folder with FSEvents and reloads the moment a file changes, so an edit made in a Claude session appears on your desktop within a frame. Edits travel both ways: what you type is just markdown on disk.

CLAUDE.md ships as a template and is written into the vault on first run, so any future session picks up the conventions unprompted.

Dates

# todo.md
- [ ] Ask about compactness  due:2026-08-12
- [ ] Send Mei the sketch    due:2026-08-10
- [ ] Submit ethics form     due:2026-08-19
- [ ] Water the plants       every:week
- [x] Re-read §3.2           done:2026-08-11

Dates are plain text, not metadata. Inline key:value in ISO 8601 — greppable, typeable, no emoji, and still readable if the renderer is gone. The widget shows them relatively (today, 2d overdue) with the absolute date on hover.

Ticking a box stamps done: automatically. A every: line rewrites itself to the next occurrence instead of being crossed off.

Type due:friday and it normalises to the ISO date on save — so both you and an agent can write loosely and the file stays canonical.

FieldAcceptsBehaviour
due:2026-08-19, 2026-08-19T14:00, friday, +3dSorts the Today view; colours amber within 2 days, red once overdue
done:2026-08-11Written when you tick the box; never entered by hand
every:day, week, 2weeks, month, mon,thuOn completion the line is rewritten with the next due:
daily/YYYY-MM-DD.mdToday's note created on first write, from a configurable template

Dates are date-only and timezone-naive — never shifted across zones. A task due the 19th is due the 19th in Melbourne and in Reykjavík. This is the single most common bug in todo apps and it's a one-line decision to avoid it.

Shipping it

foolscap/
├── Sources/FoolscapCore/  # no UI — testable
│   ├── Vault.swift
│   ├── TaskLine.swift     # due: / every:
│   └── Recurrence.swift
├── Sources/Foolscap/      # NSPanel, WKWebView
├── Tests/
├── Resources/themes/      # *.css
├── templates/CLAUDE.md
├── .github/workflows/     # macOS runner
├── build.sh · README.md · LICENSE

Split the core out of the UI. Date parsing, recurrence, and the vault model go in a module with no AppKit import, so they're unit-testable in CI without a GUI. This is the difference between a personal script and something a stranger will send a pull request to.

Nothing hardcoded. Vault path, theme, and start mode come from ~/.config/foolscap/config.toml, overridable by $FOOLSCAP_VAULT. User themes drop into the same config directory and appear in the menu.

Gatekeeper is the real distribution cost. Unsigned builds are blocked on first launch. Either document the xattr workaround in the README or pay for an Apple Developer account to notarise — worth deciding before the first release, not after.

Open questions

The name. Foolscap is a sheet of writing paper — it fits, and it's almost certainly unclaimed. It's a placeholder in exactly one place, so say the word and it changes.

Preview or source on open? Preview reads better if an agent writes most of the content; source is better if you type most of it yourself.

Scope discipline for v1. No plugin system, no cross-platform, no sync. macOS, markdown, themes — and ship it.
